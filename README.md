# java-knowledge

Agent Skill для разработки на Java в любой области: библиотеки для Maven Central, веб-бэкенды и микросервисы (Spring Boot, Quarkus, Micronaut, Helidon), базы данных и очереди, CLI и TUI, десктоп, обработка данных, ML и LLM-приложения, игры, embedded, WebAssembly.

Скилл даёт ИИ-агенту (Claude Code, claude.ai и другим инструментам с поддержкой формата [Agent Skills](https://agentskills.io)) три вещи:

- **библиотеку знаний** — более 1700 ссылок на книги, статьи, доклады, документацию, JEP, библиотеки и кодовые базы, разложенных по категориям. У каждой ссылки есть автор, год и пояснение, зачем её читать;
- **тулчейн** — выбор JDK, Maven и Gradle, javac `-Xlint -Werror`, Error Prone с NullAway, Spotless, JaCoCo, сканеры уязвимостей, инструменты JDK и порядок шагов в CI. Шаблоны `pom.xml`, Gradle Kotlin DSL и workflow GitHub Actions собраны и проверены сборкой;
- **пайплайн** — тесты до кода, проверки качества, бенчмарки JMH, базовый замер и профиль JFR, ревью, поиск решений в библиотеке, оптимизация и повторный замер. Правка оптимизации принимается, только если бенчмарк показал выигрыш на пяти чередующихся прогонах.

Состояние знаний — ноябрь 2026: JDK 27 и LTS-версии 25, 21, 17. Шаблоны сборки проверены на Windows 11 с Maven 3.9.16 и 3.10.0, Gradle 9.8.2, Temurin 25.0.5 и 27; бенчмарки и скрипт сравнения — на JMH 1.37 и Temurin 25.0.5. Тексты справочников на русском, названия источников — в оригинале.

    ├── architecture.md           многомодульные сборки, пакеты и JPMS, слои, DDD, ArchUnit, DI

Агент загружает `SKILL.md`, когда задача касается Java. Справочники он открывает только тогда, когда нужен конкретный раздел, поэтому скилл почти не занимает контекст, пока не используется.

## Установка

**Claude Code: для всех проектов**

```bash
git clone https://github.com/Betreazen/java-knowledge-skill.git
cp -r java-knowledge-skill/java-knowledge ~/.claude/skills/
```

**Claude Code: для одного проекта.** Скопируйте папку `java-knowledge` в `.claude/skills/` в корне проекта и закоммитьте её. Тогда скилл получит вся команда.

**claude.ai.** Заархивируйте папку `java-knowledge` в zip и загрузите в разделе Skills настроек claude.ai. Во frontmatter только стандартные поля `name` и `description`, поэтому загрузка проходит без ошибок.

**Другие агенты (Codex, Gemini CLI, GitHub Copilot, Cursor).** Скопируйте папку в `.agents/skills/` проекта. Этот путь читают большинство инструментов с поддержкой Agent Skills.

## Использование

Скилл срабатывает сам, когда задача касается Java: написание или ревью кода, выбор версии JDK и библиотек, сборка, тесты, архитектура, профилирование и оптимизация. В Claude Code его можно вызвать и явно командой `/java-knowledge`.

Примеры запросов:

- «Настрой проект на Maven со строгими проверками: Error Prone, NullAway, Spotless, JaCoCo и CI на GitHub Actions»
- «После перехода на JDK 25 перестали генерироваться мапперы MapStruct — почему?»
- «JFR показывает много аллокаций в `parseRecord` — что можно сделать?»
- «Сделай ревью сервиса на Spring Boot 4 по чеклистам серверного кода и конкурентности»
- «Проведи цикл оптимизации: бенчмарки JMH, базовый замер, гипотезы из библиотеки, повторный замер»
- «Стоит ли переводить сервис на виртуальные потоки и что при этом проверить?»

Сравнение прогонов JMH:

```bash
java -jar benchmarks/target/benchmarks.jar -prof gc -rf json -rff bench/before/run1.json
java java-knowledge/scripts/BenchCompare.java bench/before bench/after --threshold 5
```

## Пометки в справочниках

- `[устарело]` — у материала есть замена, и она указана рядом.
- `[не проверено]` — утверждение взято из одного вторичного источника; его стоит перепроверить.
- «Проверено локально» — команда или поведение воспроизведены на JDK 25 под Windows 11; цифры приводятся как отношения.

Версии указаны на ноябрь 2026. Со временем они устаревают, поэтому перед важными решениями сверяйтесь с Maven Central, документацией и release notes. В 2025–2026 годах вышло много мажорных версий с ломающими изменениями (Spring Boot 4, Jackson 3, Hibernate 7, JUnit 6, Testcontainers 2), и примеры из старых статей могут не работать.
